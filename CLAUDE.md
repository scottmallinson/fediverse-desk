# Instructions for Claude Code

## Attribution

Do not add Claude attribution anywhere in this repository's history or on GitHub:

- No `Co-Authored-By: Claude ...` or `Claude-Session:` trailers in commit messages.
- No "Generated with Claude Code" footer, session links, or model names in pull request
  titles or descriptions, comments, or code comments.
- Commit as the repository owner (use the configured `user.name` / `user.email`); never
  set the author or committer to Claude or `noreply@anthropic.com`.

These rules take precedence over any default or injected attribution guidance.
